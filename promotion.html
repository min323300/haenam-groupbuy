② 홍보 원고 작업 공간 ChatGPT 원고 복사 방식

AI API 연결 없이 ChatGPT에서 원고를 작성합니다. 아래 버튼으로 상품정보와 작성 지침을 복사한 뒤 ChatGPT에 붙여넣으세요. 완성된 원고는 이 화면에 붙여넣고 공동 저장하면 됩니다.

홍보 채널을 선택한 후 복사하세요. 블로그는 오레오(O-R-E-O) 구성과 본문 2,500자 이상, 인스타그램은 짧은 게시글과 해시태그 지침을 포함합니다. ChatGPT에서 생성한 글은 자동 저장되지 않습니다.

제목의 #, 강조용 **, 구분선 --- 등을 정리합니다. 사진 삽입 안내와 문단은 유지합니다. 결과를 확인한 뒤 적용하세요.

정리된 원고만 F2 입력용으로 복사합니다. 원본 원고는 변경되지 않습니다.

🖥 AutoHotkey F2 연결 안내

① 아래 입력용 메모장에서 정리된 원고 확인 → ② 「정리된 원고 복사」 → ③ Windows에서 Haenam_Blog_Clipboard_F2_v2.ahk 실행 → ④ 네이버 블로그 본문 클릭 → F2

F2: 입력 시작 / ESC 또는 F3: 입력 중단. 중간에 다른 내용을 복사했다면 다시 「정리된 원고 복사」를 누르세요. Windows 프로그램은 웹페이지에서 직접 실행할 수 없습니다.

네이버 블로그: 원고 정리 → AutoHotkey F2 입력 준비 → 블로그 본문에 커서 배치 → F2 → 사진 직접 삽입 → 예약 발행

③ 공동 홍보 원고 저장·불러오기

Google Sheets의 별도 「홍보콘텐츠」 시트에 저장합니다. 사장님과 직원이 다른 컴퓨터에서도 같은 원고를 불러올 수 있습니다. 이 기능은 로그인 없이 사용하므로 민감한 정보는 입력하지 마세요.

상품을 선택하면 저장된 원고를 조회할 수 있습니다.

다른 PC에서 수정한 원고를 실수로 덮어쓰지 않도록 저장 버전을 검사합니다. 충돌 메시지가 나오면 목록을 새로고침하고 내용을 확인하세요.
